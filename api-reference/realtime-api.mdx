<Warning>
  **This page is deprecated.** The separate "Realtime API" mode has been removed. The API now operates with a single unified endpoint that handles everything automatically.
</Warning>

## What Changed?

The `?mode=realtime` parameter is no longer needed. The API now:

1. **Automatically enriches** domains with fresh data when no recent data exists
2. **Returns cached data instantly** (for free) when the domain was enriched within 24 hours
3. **Requires a webhook URL** for new enrichment requests

## Migration Guide

| Old Way | New Way |
|---------|---------|
| `GET /company/domain.com?mode=realtime` | `GET /company/domain.com` |
| `GET /company/domain.com?mode=cached` | `GET /company/domain.com` (returns 410 if using mode=cached) |
| `mode=realtime&enrich=funding` | `enrich=funding` |

**Key changes:**
- Remove `mode=cached` and `mode=realtime` parameters
- Add `X-Webhook-URL` header (or configure in API panel)
- Handle both `200` (instant cached) and `202` (enrichment queued) responses

```bash
# New unified request - no mode parameter needed
curl -X GET "https://api.bouncewatch.com/api/v1/company/stripe.com?enrich=funding,team" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "X-Webhook-URL: https://your-server.com/webhook"
```

<Tip>
  For quick testing without a server, get a free webhook URL from [webhook.site](https://webhook.site)
</Tip>
